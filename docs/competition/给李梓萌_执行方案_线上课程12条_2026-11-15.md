## §1 你的执行步骤（1/2/3/4 同在 CSS 文件，**一次改完再交**）

### Step 1 · 第 1 条：降 AI 化配色、形成特色

1. 出一套主色方案（建议低饱和、偏纸感/墨色系，弱化「紫 + 青发光」的 AI 面板感），
   列成**色值表**交给队长同步守卫；
2. 只改 `global.css:19-82` 的 `--accent*` / `--accent-offline*` / `--accent-glow*` / `--accent-border` / `--accent-strong` 等约 15 行；
3. 🔴 **同步 `limeng.css` 36 行硬编码 rgba/hex 派生** —— 漏了会出现「紫底配新主色」的脱节；
4. `limeng.css` 的 `:root` **保持纯别名桥**（`--purple: var(--accent)` 等），不要在 root 里写死 hex；
5. 通知队长同步 `css-vars.test.mts` 的旧色值常量。

**验收**：`npm test` 全绿；用真实 Chromium 渲染 `frontend/dist` 后 `getComputedStyle()` 回读
（沿用 11/12 L1 定版的验证方式），侧栏 / 卡片 / 悬浮条 / 复习卡**没有一处残留旧紫旧青**。

### Step 2 · 第 2 条：字号体系

1. 在 `global.css:root` 新增字号 scale，例如

   ```css
   --fs-micro: 11px; --fs-caption: 12px; --fs-body: 14px;
   --fs-subtitle: 18px; --fs-title: 22px;
   ```

   （具体值你定，但要对照你自己在 `TEAM_TASK_PLAN.md:62` 定的「正文 ≥14pt」规范）；
2. **优先级**：字幕/转写区 → 识别页顶栏/侧栏 → 复习卡 → 生词本/抽屉 → 徽章类装饰文字；
   先解决「看不清」，装饰性 8px 徽章最后处理；
3. 重点规则（当前值）：

   | 类 | 现值 |
   |---|---|
   | `.current-en` / `.current-zh` | 18px / 13px |
   | `.transcript-text` / `.transcript-en` / `.transcript-time` | 13px / 10.5px / **8.5px** |
   | `.overlay-en` / `.overlay-zh` | 11.5px / 10px |
   | `.history-row-en` / `.history-time` | 10.5px / 8.5px |
   | `.transcript-current-label` / `.meter-scale` / `.due-badge` / `.rating small` | **8px** |

4. 同步 `components/ui/ui.css`（`.pill 9.5px`、`.toast 10.5px`）与 `global.css:179`（`.btn 14px`）；
   TSX 内联 `fontSize` 清单整理出来交给队长/张春阳改成 token 引用（**你不动 TSX**）；
5. 建议下限：**正文/字幕类不小于 12px，字幕正文不小于 16px**；让队长加一条守卫
   `frontend/tests/font-scale.test.mts`（CSS 中不得再出现 `font-size: 8px / 8.5px / 9px`）。

**验收**：`dist` 计算样式回读；1080p 下识别页、悬浮窗、复习卡无需凑近看；守卫锁住下限。

### Step 3 · 第 3 条：高对比度规范

1. 定义一组**具体值**（不要「再亮点」这种描述）：字幕前景 `#fff`、译文不低于 `#e6e6ee`、
   字幕底板不透明度 ≥0.85、历史行淡化上限 0.75、必要时加 `text-shadow` 描边。
   当前 `.transcript-text` 用 `var(--text-2)`、`--text-muted` 更淡，是主要问题点；
2. 写 `html[data-contrast="high"]` 覆盖规则，作用于
   `.current-*` / `.transcript-*` / `.overlay-*` / `.history-*`，
   **只改 color / background / text-shadow，不改布局与字号**（避免与 Step 2 冲突）；
3. 把「开关放哪、class 怎么挂」按 C2 告诉张春阳；若走 `OverlaySettings.highContrast`，
   提醒队长同步三处默认值 + `SCHEMA_VERSION` 4→5；
4. 悬浮窗 `OverlayWindow.tsx:119-135` 的历史行 `opacity: 0.28…` 与 `textBgOpacity` 也纳入规范，
   这部分 TSX 由张春阳按你给的值改。

> ⚠️ 目前唯一能调字幕颜色/底色的 UI 是 `OverlayControlPanel`，但它只挂在未挂载的旧页 ——
> 张春阳的 Step 3 会把它接进主路由，**你的开关落点依赖他那一步**。

### Step 4 · 第 5 条：视频填满的布局 CSS

按 C2 约定写（张春阳只加 class）：

```css
.web-view-guest { display:block; width:100%; height:100%; border:0; }
.web-content { height: min(70vh, 720px); min-height:380px; }   /* 现在只有 min-height */
.recognition-page.web-fill .recognition-grid { grid-template-columns: 1fr; }
.recognition-page.web-fill .recognition-side { /* 收起或叠在视频上，由你定 */ }
```

⚠️ 视频填满时**字幕必须有可读底板**（当前句 / 悬浮条），否则白底视频页面上白字会消失 —— 与 Step 3 一起验。

### Step 5 · 第 4 条视觉 + 演示视频

- 「帮助与关于」页（`components/HelpAboutPanel.tsx`）做视觉润色；文案由队长补，你不动文案源文件；
- 改完后录 ≤3 分钟演示视频成片（课程列表 → 配置 → 识别 → 出字幕 → 点词讲解 → 导出），交朱鸿康做证据。
