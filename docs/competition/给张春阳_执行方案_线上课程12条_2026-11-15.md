## §0 动手前必读的 5 条契约

### C1 🔴 后端字幕行 ≠ 前端 `SubtitleLine`（最容易写错）

`GET /api/courses/{id}/subtitles?limit=200` 返回**裸数组**、按 `start_ms DESC` **倒序**。字段映射：

| 后端 | 前端 `SubtitleLine` | 处理 |
|---|---|---|
| `id` | `id` | 值是 DB uuid（实时行是 `sub_N`），只作 key；**不要**拿它等译文消息 |
| `text` | `text` | 直接 |
| `translation` | `translation?` | 后端是 `''` → 转 `undefined` |
| `words` | `words` | 已由 `words_json` 解出，非数组要兜底 |
| **`start_ms` / `end_ms` / `is_final`** | **`start` / `end` / `isFinal`** | **改名** |

> **不能把后端行直接传给 `toDisplayLine()`** —— 它 `lineTime()` 读 `line.start` 会拿到 `undefined` → `NaN:NaN`。
> 译文已在库里，**不要**再等 `subtitle_translation`（那条用实时 `client_id`，匹配不上 DB uuid）。

```ts
// frontend/src/shell/lib/mapping.ts 新增
export interface SubtitleRow {
  id: string; text: string; translation?: string; words?: unknown
  start_ms: number; end_ms: number; is_final: boolean
  session_id?: string; chapterId?: string; createdAt?: number
}
export function fromBackendRow(row: SubtitleRow): SubtitleLine {
  return {
    id: row.id,
    text: row.text,
    translation: row.translation || undefined,
    words: Array.isArray(row.words) ? row.words as SubtitleWord[] : [],
    start: row.start_ms,
    end: row.end_ms,
    isFinal: !!row.is_final,
  }
}
```

### C2 端点速查

| 端点 | 返回 |
|---|---|
| `GET /courses/{id}/subtitles?limit=&chapterId=` | 裸数组；**只支持 limit / chapterId，不支持 sessionId** |
| `GET /courses/{id}/sessions` | `{sessions:[{sessionId,startedAt,count,firstText,isLatest}],total}`；老库 `session_id=''` 不进桶 |
| `GET /courses/{id}/export-srt?offsetMs=&sessionId=` | `{srt,count,offsetMs,sessionId}`，**JSON 无下载头 ⇒ 必须前端 Blob 落盘** |
| `POST /courses/{id}/summary` | 成功 `{available:true,subtitleCount,wordCount,summary,key_points,review_words}`；LLM 不可用是 **503 `{detail}`** |
