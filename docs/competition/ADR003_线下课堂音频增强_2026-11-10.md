## 0. 增量需求（11/10 16:53）：麦克风测试

队长追加：线下课配置页要有**「麦克风测试」**按钮/弹窗。定位为 §2 ① 电平条的延伸，不是独立功能：

- 交互：选设备 → 点「试采 3 秒」→ 实时电平条跳动 → 回听录音 → 给出判定「电平良好 / 声音偏小 / 没检测到声音」（后两者提示换设备或靠近讲台）；
- 纪律：**试采不写入课程、不启动识别、不落盘留存录音**（只在内存里回听），避免隐私与脏数据；
- 接口草案：`POST /api/audio/mic-test { deviceIndex }` → `{ level: 0..1, verdict: "good"|"low"|"silent", wavBase64? }`（回听音频走临时内存对象，不写文件）；
- 验收补充：静音环境下必须判 `silent`；说话时 3 秒内出判定；重复测试不残留采集线程（注意 `capture.py` 的 PortAudioGuard 全局锁）；
- 排期：并入 §5 张春阳 11/13–15（前端弹窗）+ 朱鸿康 11/13–15（后端试采接口），**增量约 0.5 天，不新开窗口**。

## 1. 现状能力边界（代码实测）

线下模式**不是空白**，但采集链路很「裸」：

| 已有 | 没有 |
|---|---|
| `courseType: online/offline`，offline 走麦克风 | ❌ 麦克风设备选择 UI（后端 `AudioCapture.list_devices()` 已有，前端没用） |
| `audio/capture.py`：16kHz 单声道、默认输入设备或手动 `device_index` | ❌ 实时电平指示（选错麦/没声音无法自查）——教室第一痛点 |
| Silero VAD（pipeline 按 mode=microphone 构造） | ❌ 增益 AGC / 降噪 / 远场 VAD 参数档 |
| 配置页「靠近讲台」「建议降噪麦克风」文案 | ❌ 任何线下端到端 E2E 验证记录 |

## 2. 功能候选与取舍

| # | 功能 | 方案 | 工作量 | 结论 |
|---|---|---|---|---|
| ① | **麦克风设备选择 + 实时电平条** | 配置页下拉列出输入设备（复用 `list_devices`）+ RMS 电平条 + 「没检测到声音」提示；电平随 `GET /api/asr/poll` 附带 `inputLevel` 返回，不新增轮询 | 1 天 | ✅ **必做** |
| ② | **输入 AGC + 轻量降噪** | numpy 实现 RMS 自动增益（远场老师声音小）+ 100Hz 高通（空调低频）+ 保守谱减；**禁止引入 RNNoise / 深度降噪模型**（CPU 实时与打包风险） | 1.5–2 天 | ✅ **必做** |
| ③ | **教室远场 VAD 档** | offline 课程自动用更长 `min_silence` / `speech_pad`、略低阈值；配置页可切「近讲 / 远场」 | 0.5 天 | ✅ 做 |
| ④ | 板书拍照 → OCR 补术语 | 拍照识别板书名词写入术语框 | ≥3 天 | ❌ 进路线图 |
| ⑤ | 说话人分离（老师/提问同学） | — | ≥3 天 | ❌ 不做 |

## 3. 接口草案（承接人评审后定稿）

```
GET  /api/audio/devices          → { devices: [{ index, name, isDefault, channels }] }   # 复用 AudioCapture.list_devices
POST /api/asr/start  请求体新增 →  { micDeviceIndex?: int, agc?: bool, vadProfile?: "near"|"far-field" }
GET  /api/asr/poll    响应新增   →  { inputLevel: 0..1, agcGainDb?: number }
```
> ⚠️ 设备枚举有跨进程 PortAudioGuard 全局锁（capture.py §注释），**电平轮询不得触发重复枚举**；设备列表只在打开配置页时拉一次。

## 4. 验收标准

1. **量化验证**：用现有 `testset/chinese_lecture/real/*.wav` 合成 10dB 教室噪声（空调底噪 + 翻书/低语），对比增强前后 CER——要求**不劣化**；评估脚本必须 `--realtime`（§4.3 纪律）；
2. 切换麦克风设备后 **≤2s** 生效；说话时电平条跳动、静音 10s 提示「没检测到声音」；
3. 线下 E2E 真验证一次（新建线下课程 → 麦克风收音 → 出字幕 → 点词 → 复习），截图归档 proof；
4. 门禁：pytest ≥524/1（新增音频处理单测）、前端 ≥209/0 fail、`tsc --noEmit` 0、CodeCheck 新增代码零严重项。
