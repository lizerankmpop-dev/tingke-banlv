## §〇 产品定位（一句）

> **让课堂/网课的内容，在听课当场变成能点、能查、能复习的文本资产。**

**三个不可让渡的承诺**（任何设计取舍与这三条冲突时，改设计不改承诺）：

| # | 承诺 | 为什么是它 |
|---|---|---|
| 1 | **课堂音频不出本机** | 唯一能进校园网、无网学生也能用的前提；也是隐私差异点 |
| 2 | **离线可用**（模型内置、首启不下载） | 校园网计费/网络波动 ⇒ 联网下载 = 装完不能用 |
| 3 | **不承诺没做的事** | 25 分「贴合度」考的是可信度，不是功能数量 |

## §一 北极星目标与三个可度量目标

**北极星**：一节课结束后，学生手里有 **一份可回看的字幕 + 一份可复习的生词本**，且两者是**同一次听课**产生的。

| 目标 | 度量 | 现状 | 达成判定 |
|---|---|---|---|
| **G1 字幕「当场」可用** | 端到端延迟 | ✅ **≈8 秒**（11/11 从 ≈16s 修复） | 片段上限 6.0s，最坏延迟 ≤ 8s |
| **G2 内容「带得走」** | 导出可用性 | ✅ SRT + 生词 CSV + 备份 JSON | 导出后能进别的工具继续用 |
| **G3 生词「回得来」** | 复习闭环完整度 | 🟡 **缺一个入口**（见 F5） | 从「听到生词」到「进复习队列」**全程无断点** |

> **G3 是当前唯一的实质缺口** —— 而它恰好是「链路的起点可能整个断掉」的形态。
> 这就是《产品弱点改进方案》§六 建议做「手动添加生词」的根据。

## §三 逐条展开（问题 → 目标 → 判定 → 现状 → 差距）

### F1 实时字幕 ✅（本期最关键的修复在这）

**问题**：课堂是**流式**的，字幕晚 3 句话，就等于「听懂了也用不上」。

**目标**：内容在**说话结束后 1 个片段内**上屏。

**达成判定**：片段长度严格受上限约束（≤6.0s + 0.032 容差）；端到端最坏延迟 ≤ 8s。

**现状**：✅ 11/11 修复「最长片段保护从未生效」三层根因，**≈16s → ≈8s**；参数 6.0s 由**生产引擎端到端**在 420s 真实音频上扫档位定出（5.0s 处准确率断崖：CER 39.06% vs 6.0s 的 20.17%）。

**差距**：更低延迟需要真正的流式解码（改推理架构）⇒ 赛后路线图。

---

### F2 字幕语言选择 + 双语渲染 ✅

**问题**：中文课要原文，英文课要译文，有的场景要对照。

**目标**：建课时选课型与语言，同一份字幕可切换「原文 / 译文 / 双语」。

**达成判定**：`subtitle_lang` 落库；双语模式下中文与译文合并为同一行字幕。

**现状**：✅ 11/10 合入（`feat/lang-chapters`）。

---

### F3 章节管理 ✅

**问题**：一门 20 集的网课，字幕全堆在一起没法回看。

**目标**：课程内建章节，字幕按章节归属，可按章筛选。

**达成判定**：章节 CRUD 三个端点 + 字幕写入带 `chapter_id` + 按章查询。

**现状**：✅ 11/10 合入。

> ⚠️ 相关坑已修：`idx_subtitles_chapter` 索引建在迁移加列之前 ⇒ **老用户升级打不开应用**，
> 11/12 打包实测抓出并修复，已加结构守卫测试防复发（见 `RELEASE-NOTE-v3.8.0.md`）。

---

### F4 点词查义 + AI 弹卡 ✅

**问题**：生词当场不查，过后就想不起来了。

**目标**：点任意词 → 弹卡给释义、例句、上下文，可继续问 AI。

**达成判定**：`/api/ai/explain`、`/api/ai/ask` 可用；无 Ollama 时**优雅降级**（不弹错误、字幕照常）。

**现状**：✅ 已实现；降级路径已验证。

---

### F5 生词本 + SM2 复习 🟡 **← 唯一实质缺口**

**问题**：课堂生词是**一次性消费** —— 不存下来，等于没学过。

**目标**：生词进本 → SM2 排期 → 到期复习 → 掌握度可追踪。

**达成判定**：SM2 调度正确；到期队列可查；复习页可用；生词可导出 CSV 给外部工具。

**现状**：🟡 **复习闭环本身完整**（`vocabulary/backup.json`、`review-queue`、`stats`、`export.csv`、`due-summary` 五个端点 + 复习页 + 回顾提醒）。

**缺口（关键）**：**没有「新增生词」的入口**。
- 现在的生词来源只有两条：**字幕里点词自动收集**、**资料上传自动提取术语候选**；
- ⇒ **非课堂场景**（看教材、读论文、听播客）产生的生词，**整条链路起点就断了**；
- ⇒ 生词本是「**单点依赖**」：那条唯一入口不通，整个复习闭环就是空的。

**赛内要做的（F11）**：补一个「手动添加生词」入口 —— 纯增量、零算力、不碰识别链路。

---

### F6 课程资料上传 ✅

**问题**：AI 讲解是泛泛而谈的，因为它不知道这门课在讲什么。

**目标**：把讲义/课件喂进去，AI 讲解能引用本课内容。

**达成判定**：上传/列表/删除 + 自动提术语候选 + 术语与资料进答疑上下文。

**现状**：✅ ADR-004 L1 已实现（`materials` 表 + 三个端点 + 术语候选端点）。

**边界**：L1 只登记 + 纯文本进上下文；PDF/PPT 全文解析未做（赛后）。

---

### F7 线下课堂音频增强 ✅

**问题**：阶梯教室录不清 ⇒ 字幕全错。

**目标**：让线下课的收音达到「能用」。

**达成判定**：麦克风设备可选 + 实时输入电平可见 + 谱减降噪 + AGC 自动增益。

**现状**：✅ ADR-003 已实现（`/audio/devices`、`/audio/check-loopback`、`/asr/microphone`）。

**待补**：**10dB 加噪 A/B 评测报告**（F13）—— 这是**证据缺口**不是功能缺口，但话术依赖它。

---

### F8 课程内嵌网页方框 ✅

**问题**：网课场景下，视频在浏览器里、字幕在另一个窗口，来回切很打断。

**目标**：把网页拖进课程页的方框里，和实时字幕并排。

**达成判定**：拖入保留在页面 + guest 隔离（拿不到宿主权限、带不走本地文件）。

**现状**：✅ ADR-002 已实现（`CourseWebview.tsx` + `course-webview.cjs`）。

---

### F9 导出 ✅

**问题**：内容锁在软件里 = 用户没有掌控感。

**目标**：字幕与生词能带走。

**达成判定**：SRT 导出（按 `session_id` 分隔，避免多会话时间轴重叠）；生词 CSV；备份 JSON 可恢复。

**现状**：✅ 已实现。

> ⚠️ **事实核查**：`export.csv` 的注释写「供 Anki 导入」——**Anki 导入本身没有实现**，
> 且标准 Anki 导入不支持调度字段（依赖第三方插件，2021 后未更新）⇒ **答辩只能说「导出 CSV，可自行导入外部工具」，不能说「支持 Anki 无缝同步」**。

---

### F10 离线优先 + 隐私 ✅（贯穿性，不是某个页面）

**目标**：课堂音频永不出本机；没网也能上课。

**达成判定**：本地推理 + 模型内置 141MB 首启不下载 + 导出只带文本与生词（不含音频）+ 无云端上传。

**现状**：✅ 打包已验证（`resources/whisper_models` 内置，preflight 硬校验种子完整性）。

| 4 | 🔴 **平台留痕闭环**（CI/CodeCheck/MR/九项截图） | 张春阳侧 | 张春阳 | 11/13 | 25 分硬缺口，见《给张春阳_最新成果简报》 |

## §五 明确不做（收口纪律）

| 不做的东西 | 为什么 | 怎么对外说 |
|---|---|---|
| 说话人分离 | 需 1.5–2 天 + 新建字幕回看页；且**课中快捷键到达率低**（研讨课里根本没机会点） | 「主入口设计为**课后回看批量标注**，不在课中做实时切换」（已改口径） |
| 先录后转 | 1.5–2 天 | 「赛内聚焦实时场景，录后转写是路线图」 |
| 跨设备复习 | P1 PWA + L2 双向同步是**另一个产品** | 「本地优先，不做账号体系」——**别说「跨设备 SM2 已做」** |
| Anki 导入 | 标准导入不支持调度字段，依赖停更插件 | 「导出 CSV / JSON，**可自行导入外部工具**」 |
| 移动端 App | 11/10 已定：网页伴侣不做 | — |
| 任何新增 UI 皮肤/换肤 | 三套色值已收敛到 token 层面 | — |

**统一话术四不**：不承诺未做的 / 不跟竞品同质化 / 不把证据缺口说成功能缺口 / **不把「一次性快照」说成「跨设备 SM2 同步」**。
