## §〇 一句话结论

**产品功能本体 F1–F10 基本齐备，v3.9.0 整体换骨架没有造成大面积退化；差距集中在四处：**

1. **复习链路的起点**（F5 → F11）；
2. **一处静默退化**（F3 章节选择在重构中丢失，目标文档仍标 ✅）；
3. **证据与交付物**（10dB 加噪报告、访谈纪要、留痕、五文件夹）；
4. **文档数字全线过期**（586/223 的口径还挂在四份文档里）。

> 🔴 **最急的不是加功能，是把「证据」和「口径」补齐** —— 评分表 25 分的「专业贴合」、
> 30 分的「功能完备度」都直接吃这两样；功能缺口里有两个其实只差前端入口。

## §六 明确不做（防范围蔓延，也是对外话术）

| 不做 | 理由 | 怎么说 |
|---|---|---|
| 说话人分离 | 1.5–2 天 + 课中快捷键到达率低 | 「主入口设计为课后回看批量标注，不在课中做实时切换」 |
| 先录后转 | 1.5–2 天 | 「赛内聚焦实时场景，录后转写是路线图」 |
| 跨设备 SM2 | 是另一个产品 | 「本地优先，不做账号体系」 |
| Anki 导入 | 标准导入不支持调度字段，依赖停更插件 | 「导出 CSV/JSON，可自行导入外部工具」 |
| 移动端 App / 换肤 | 11/10 已定 / 色值已收敛到 token | — |
| 更低延迟（真流式解码） | 需改推理架构 | 「片段上限已从实际 15s 修到 6s，端到端约 8s；更低需流式解码，属赛后」 |

**统一话术四不**：不承诺未做的 / 不跟竞品同质化 / **不把证据缺口说成功能缺口** / **不把一次性快照说成跨设备 SM2 同步**。
