## 第 0 步：拿压缩包

- 微信群里领 **`win-unpacked-4.0.0.zip`**（约 **363MB**，976 个文件）；
- ⚠️ **先把 zip 复制出来再解压**：微信收到的文件是只读的，直接在微信缓存目录里解压容易出权限问题。复制到 `D:\` 或桌面这种普通目录，例如 `D:\tingkebanlv\`。

> 💡 **本版是升级包**：如果你之前用过 3.7.x / 3.8.x / 3.9.0，**直接解压覆盖即可** —— 课程、字幕、笔记、生词全部保留。
> 老库升级已实测（老库 3 门课程 + 14 条字幕 → 4.0.0 后端：`course_notes` 自动建表、数据逐条无损），**升级是安全的**。

## 第 1 步：解压

- 右键 zip → **「全部解压缩」**（Windows 自带的就行），别用压缩软件「直接打开后双击运行」；
- 解压后约 **900MB**，确保目标盘剩余空间 **≥2GB**；
- 解压完得到一个 `win-unpacked` 文件夹，里面直接就是 `听课伴侣.exe`。

## 第 2 步：双击 `听课伴侣.exe`

按顺序处理三个系统提示（都会遇到，正常现象）：

| 提示 | 怎么办 |
|---|---|
| 🔵 蓝色 SmartScreen：「Windows 已保护你的电脑」 | 点**「更多信息」→「仍要运行」**（程序未做代码签名，每次首启都会问） |
| 🟡 杀毒软件（360/火绒/Defender）报「可疑程序」 | 选**允许/信任**；如果 `听课伴侣.exe` 或后端被静默删了，退出杀软后重新解压 |
| 🟠 防火墙弹窗 | 点**允许访问**（仅限专用网络即可） |

**首次启动等 1~2 分钟**：程序会自己拉起内置后端（模型已内置，141MB，**不需要联网下载，全程可离线跑**）。期间**不要重复双击**——多开会抢 8765 端口，窗口弹不出来。

## 第 3 步：出字幕 + 截图（5 分钟）

1. 左侧栏点**「新建课程」**：名字随便（如 `test`），模式选**线上课**，语言选**英语**；
2. **直接点课程卡片**（新界面点卡即进入识别页并自动开始识别）；
3. 播放一个英文网课视频（B站搜 "MIT 算法"，或任何英文讲课视频），**声音外放、音量开到能听见**；
4. 等 **8~15 秒**，字幕开始往外蹦（🔴 延迟已从 ≈16 秒降到 ≈8 秒）；
5. **截图发群** ✅（字幕文字 + 右下角任务栏时间，两张要素缺一不可）。

> 点生词弹 AI 讲解面板、点「AI 生成术语」都需要装 Ollama 或配云端密钥，**本次验收不需要**——字幕出来就算过。
> 结束时**先点「停止识别」再关窗口**，别直接杀进程。

## 常见翻车速查

| 症状 | 解法 |
|---|---|
| 双击后**完全没反应** | 多半是杀软静默拦截 → 看杀软隔离区/退出杀软重试；确认是解压后的 exe，不是 zip 里的 |
| SmartScreen 蓝框卡住不敢点 | 「更多信息」→「仍要运行」，这是我们自己的程序 |
| 界面提示**后端连不上** | 杀软拦了内置后端 `tingkebanlv-server.exe` → 加信任后重启程序 |
| 课程列表一直「还没有课程」 | 8765 端口被占了：cmd 跑 `netstat -ano \| findstr 8765`，有 LISTEN 就**重启电脑**再试（Windows 强杀进程会留僵尸端口，重启最省事） |
| 点课程卡但**不出字幕** | ① 视频真的在播且有外放音量；② 识别页顶部是否显示「识别中」；③ 返回课程页重新点一次 |
| 🆕 **点「AI 生成术语」提示失败** | 正常：本机没装 Ollama、也没配云端密钥。字幕与识别完全不受影响；想演示这个按钮需先启动 Ollama 或配置 `TINGKEBANLV_CLOUD_API_BASE/_KEY/_MODEL` |
| 中文课字幕**字与字之间有空格** | 已含 11/09 中文空格修复，理论上不会出现；若仍看到，截图发群里登记（不用自己排查） |
| 窗口白屏 | 关掉重开一次；还白屏群里喊张春阳 |
| 🔴 **提示「后端启动失败」/ 数据库报错** | 请用群里**最新发的 4.0.0 包**。3.8.0 初版曾有「老库升级打不开」的 bug，已修 |
| 界面还是**旧的三栏** | 拿的是旧包 → 重新领 `win-unpacked-4.0.0.zip`（新版是左侧栏 + 五屏） |
