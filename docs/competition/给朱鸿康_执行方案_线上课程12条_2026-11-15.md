## §0 你需要知道的契约

**端点与字段**（实测，用于写实测脚本）：

| 端点 | 返回 / 关键字段 |
|---|---|
| `GET /api/courses/{id}/subtitles?limit=&chapterId=` | 裸数组，按 `start_ms DESC` 倒序；行含 `session_id` / `chapterId` / `createdAt` / `translation` |
| `GET /api/courses/{id}/sessions` | `{sessions:[{sessionId,startedAt,count,firstText,isLatest}],total}`；老库 `session_id=''` 不进桶 |
| `GET /api/courses/{id}/export-srt?offsetMs=&sessionId=` | `{srt,count,offsetMs,sessionId}` |
| `POST /api/courses/{id}/summary` | 200 `{available,subtitleCount,wordCount,summary,key_points,review_words}`；LLM 不可用是 **503 `{detail}`** |
| `GET /api/asr/poll` | `{messages,status,stats}`；延迟实测读 **`stats.whisper.backlog` / `mergedCalls` / `droppedSegments`**，另有 `inputLevel` |

**延迟参数现状**：`MAX_SPEECH_DURATION = 6.0s`（`TINGKEBANLV_VAD_MAX_SPEECH`）、
`SILENCE_DURATION = 0.8s`、`far-field` 档 `+2.0s`（`vad.py:80-85`）⇒ 理论最坏 ≈8s / 10s；
`whisper_engine.py:808-810` 的 `beam_size=5` / `vad_filter=False` 写死；
`/asr/config` 目前只能改 `termAutoDegrade`。

**文件独占**：你只写 `codearts_proof/**` 与测试报告；
`backend/**`、`frontend/tests/**` 归队长，`frontend/src/shell/**` 归张春阳，CSS 归李梓萌。
