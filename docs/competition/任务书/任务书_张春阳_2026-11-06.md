## 四、技术要点（从复刻手册节选，完整版见 `CODEARTS_REPLICATION.md`）

### 4.1 环境搭建
```bash
# 前端
node -v        # 期望 v20.x
cd frontend && npm install

# 后端
cd backend
python -m venv .venv && .venv\Scripts\activate
pip install -r requirements.txt

# 本地 LLM（独立安装 Ollama 后）
ollama pull qwen2.5:7b
ollama pull nomic-embed-text
```

### 4.2 联调机制（务必理解，别"优化"）
- 前后端通信是 **HTTP 轮询 500ms**（`POST /asr/start` + `GET /asr/poll`），**不是 WebSocket**——这是稳定性攻坚后的定稿架构，**禁止改成 WS**；
- Electron 主进程动态分配端口、拉起 Python 后端、轮询 `/api/ping` 探活；
- 健康检查：`GET /api/ping`。

### 4.3 你大概率会踩的坑（提前给你排好雷）
1. **代理劫持**：云环境有 `http_proxy` 时，验证后端必须用 `ProxyHandler({})` 直连，否则看到的是代理响应；
2. **僵尸端口**：Windows 强杀后端留下 LISTEN 但无进程的死端口，新进程 bind 失败 `[Errno 10048]`；只看端口的健康检查会误判"服务还活着"；
3. **NSIS 静默安装**：`setup.exe /S` 可能退出码 0 但啥都不装——以"目标目录出现 听课伴侣.exe"为唯一判据，等价用 `release/win-unpacked/` 便携版；
4. **CRLF 三个文件别归一化**：`scripts/verify_install.py`、`scripts/eval_asr_quality.py`、`testset/chinese_lecture/metadata.json`；
5. **PyInstaller**：`npm run backend:build` 的 `python` 必须解析到装了 PyInstaller 的 venv；
6. **云桌面兼容模式**：华为云主机多虚拟化环境，Electron 需 `--no-sandbox --tingkebanlv-compat`；
7. **录屏黑屏**：渲染冻结用根治开关 `--disable-renderer-backgrounding --disable-background-timer-throttling --disable-backgrounding-occluded-windows --disable-features=CalculateNativeWinOcclusion`。

> 以上 1/2/3 条正是你《调试排错实录》的现成素材——遇到新坑也随时记进去。
