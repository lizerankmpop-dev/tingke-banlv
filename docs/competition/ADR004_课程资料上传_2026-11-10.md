## 1. 为什么做（别做成存文件的摆设）

代码现状：`routes.py` 无任何上传接口；`rag.py` 只切字幕片段、向量库为进程内 InMemoryVectorStore；前端无上传 UI。资料上传必须接进既有能力链，否则只是个文件夹：

| 用途 | 接哪里 | 价值 |
|---|---|---|
| ① **术语候选** | 纯文本资料抽候选专名 → 一键追加到**自定义术语框**（V7 术语层，P4 WER 0.1092） | 「识别准」卖点的第二来源，比用户手填更省力 |
| ② **答疑上下文** | 纯文本切片进 `rag.py` 现有切分/向量库 | AI 讲解能引用课件，而不只最近几句字幕 |
| ③ **课程归档** | 文件与课程绑定，导出/复习时可见 | 问卷 82.3%「课后找不到按课堂内容整理的材料」 |

## 2. 范围：L1 本次做，L2 进路线图

| 档 | 内容 | 结论 |
|---|---|---|
| **L1** | 上传/关联课程/列表/删除；**TXT、MD 直接抽文本**（术语候选 + 入 RAG）；PDF/PPT/DOCX 本次**只登记不解析** | ✅ 本次做，约 1 天（前端 0.5 + 后端 0.5） |
| L2 | PDF/PPT/DOCX 解析（PyMuPDF / python-pptx）、自动抽术语、扫描件 OCR | ❌ ≥2 天且引入新依赖/中文 PDF 文本层不稳，进路线图答辩讲 |

> 界面：配置页独立窗口，虚线拖入框 + 已关联资料列表（大小/状态/移除）+「追加候选术语到术语框」；**边框色跟随场景主题**（线上紫 / 线下青），见《线上线下界面区分设计方案》§0 与第四张示意图。

## 3. 存储与接口草案

```
目录：~/.tingkebanlv/materials/<course_id>/<sanitized_filename>
元数据：SQLite 新增 materials 表（id, course_id, name, size, ext, created_at, indexed: bool）
POST   /api/courses/{id}/materials        multipart 上传；扩展名白名单 + ≤20MB + 文件名消毒
GET    /api/courses/{id}/materials         列表
DELETE /api/courses/{id}/materials/{mid}   删文件 + 删元数据（事务）
POST   /api/courses/{id}/materials/terms   仅 TXT/MD：返回候选术语数组，前端追加进术语框
```
> ⚠️ 目录按 course_id 隔离，验收必须验证「A 课资料不出现在 B 课」。文件不执行、不写临时目录外的路径。

## 4. 与 ADR-001 的关系（重要取舍）

**「资料驱动术语」比「LLM 凭课程名凭空生成术语」更可信、更贴真实课堂**：课件里的词就是老师要讲的词。建议把 ADR-001 降级为「**资料优先、LLM 兜底**」——没有上传资料时才走本地 Ollama 生成，华为云 API 增强移入路线图。这样：

- 不抢 11/13–18 的开发窗口；
- 减少一个「AI 编术语」的答辩风险点（评委最容易质疑生成的词不准）；
- 码道叙事反而更完整：资料 → 术语层 → 识别 → 点词 → SM2，全链路有据可查。

## 5. 验收标准

1. 线上/线下课程配置页都能看到上传窗口，且边框颜色分别随紫/青主题；
2. 上传 TXT/MD 后能列出候选术语，点「追加」写进自定义术语框（**可手动删改**）；PDF/PPT 上传成功但标记「暂不解析」；
3. 删除资料后文件与元数据都不残留；A/B 课资料互不串；
4. 门禁：pytest ≥524/1（新增 materials 单测）、前端 ≥209/0 fail、tsc 0、CodeCheck 新增代码零严重项。
