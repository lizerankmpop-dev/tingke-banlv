### C1 🔴 后端字幕行 ≠ 前端 `SubtitleLine`（最容易写错的一处）

`GET /api/courses/{id}/subtitles?limit=200` 返回**裸数组**，按 `start_ms DESC` **倒序**。
每行经 `_row_to_dict()`（`backend/database/manager.py:942-1003`）后的真实字段：

| 后端字段 | 前端 `SubtitleLine` | 处理 |
|---|---|---|
| `id` | `id` | 值语义不同：后端是 DB uuid，实时行是 `sub_N`；只作 key，不参与译文匹配 |
| `text` | `text` | 直接 |
| `translation` | `translation?` | 后端是 `''`，要转 `undefined` |
| `words` | `words` | 已由 `words_json` 解出，可能非数组要兜底 |
| **`start_ms`** | **`start`** | 改名 |
| **`end_ms`** | **`end`** | 改名 |
| **`is_final`** | **`isFinal`** | 改名（已是 bool） |
| `session_id` / `chapterId` / `createdAt` | 无 | 会话分组用 `session_id`（**注意不是驼峰**） |

**必须写适配器，不能把后端行直接传给 `toDisplayLine()`** —— 后者 `lineTime()` 读 `line.start` 会拿到 `undefined` → `NaN`。

```ts
// frontend/src/shell/lib/mapping.ts 新增（张春阳）
export interface SubtitleRow {
  id: string; text: string; translation?: string; words?: unknown
  start_ms: number; end_ms: number; is_final: boolean
  session_id?: string; chapterId?: string; createdAt?: number
}
export function fromBackendRow(row: SubtitleRow): SubtitleLine {
  return {
    id: row.id,
    text: row.text,
    translation: row.translation || undefined,
    words: Array.isArray(row.words) ? row.words as SubtitleWord[] : [],
    start: row.start_ms,
    end: row.end_ms,
    isFinal: !!row.is_final,
  }
}
```

> 译文已在库里（`routes.py:492` 注释明写「历史加载路径直接读库」），
> **不要**再等 `subtitle_translation` 消息 —— 那条消息用的是实时 `client_id`，匹配不上 DB uuid。
