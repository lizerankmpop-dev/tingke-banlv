# 02 · 字号表（视觉 owner · 2026-11-15）

> 目标：按执行方案第 2 条，建立统一字号 scale，先解决「看不清」，再处理装饰性小字。
> 原则：**只改 `font-size / line-height`，不改宽高和布局**；字幕/转写区优先。

## 1. 新字号 token（写在 `global.css:root`）

```css
:root {
  --fs-micro: 11px;        /* 徽章、时间戳、量表刻度：最小字号 */
  --fs-caption: 12px;      /* 说明文字、历史字幕、次级信息 */
  --fs-ui: 13px;           /* 顶栏、面板标题、按钮、导航 */
  --fs-body: 14px;         /* 正文、译文、设置项 */
  --fs-subtitle: 16px;     /* 字幕正文/转写正文：下限 16px */
  --fs-subtitle-lg: 18px;  /* 当前句英文、复习卡大词附近 */
  --fs-title: 22px;        /* 页面标题 */
  --fs-display: 28px;      /* 复习卡单词等展示型大字 */
}
```

## 4. `limeng.css` 119 处 `font-size <= 12px` 的统一处理

不要一条条猜，按下面的**兜底规则**批量替换，再对上面重点类做精确覆盖：

| 原值 | 替换为 | 结果 |
|---:|---|---:|
| 8 / 8.5 / 9 / 9.5px | `var(--fs-micro)` | 11px |
| 10 / 10.5 / 11px | `var(--fs-caption)` | 12px |
| 11.5 / 12 / 12.5px | `var(--fs-ui)` | 13px |
| 13 / 13.5 / 14px | `var(--fs-body)` | 14px |
| 16px 及以上 | 保持，或按场景映射到 `--fs-subtitle*` | 不变/更大 |

> 装饰性 8px 徽章也统一抬到 11px。执行方案允许「装饰性徽章最后处理」，但既然门禁要锁 8/8.5/9px，就一次抬到 11px，避免二次返工。
