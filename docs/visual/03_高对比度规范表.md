## 3. 悬浮窗 TSX 要改的值（张春阳）

`OverlayWindow.tsx:119-135` 附近：

| 项 | 普通模式 | 高对比模式 | 说明 |
|---|---:|---:|---|
| 历史行 `opacity` | `0.45` | `0.75` | 现在最低到 0.28，太淡 |
| `textBgOpacity` | `0.85` | `0.92` | 字幕底板不透明度 |
| 当前句 `opacity` | `1.0` | `1.0` | 不变 |
| 历史行最多条数 | 3–4 行 | 3–4 行 | 不改布局 |

如果 `textBgOpacity` 是用户可调项，高对比模式下应**强制下限 0.85**，不要允许用户拉到 0.3。

## 4. 开关落点（给张春阳）

- 首选：`OverlaySettings.highContrast`（队长改 schema：三处默认值 + `SCHEMA_VERSION` 4→5）；
- 挂载：`Shell.tsx` 根据设置给 `<html>` 加 `data-contrast="high"`；
- 入口：`OverlayControlPanel` 里加「高对比字幕」开关；如果 Step 3 还没接进主路由，先在 `ConfigPage` 放一个全局开关兜底，由队长定。

## 5. 验收

- [ ] 浅色视频画面上，开高对比后字幕仍可读（白字 + 深底板）；
- [ ] 历史行不再「越看越淡」到看不见（≤0.75 上限）；
- [ ] 悬浮窗在浅色网页上也不消失；
- [ ] 高对比只改颜色/底板/描边，不改字号和布局。
