# 01 · 色值表（视觉 owner · 2026-11-15）

> 目标：按执行方案第 1 条，**降 AI 化配色、形成特色**。
> 方向：低饱和、偏纸感 / 墨色系，弱化「紫 + 青发光」的 AI 面板感；保留线上/线下双色识别，但不靠荧光。

## 1. 新主色

| 场景 | 主色 | 色名 | RGB | 用途 |
|---|---|---|---|---|
| 线上 | `#5F6F96` | 墨靛 | `95, 111, 150` | 线上主按钮、选中态、线上左竖条、线上胶囊 |
| 线下 | `#5F8F84` | 黛青 | `95, 143, 132` | 线下主按钮、选中态、线下左竖条、电平/状态 |

两个颜色都压低了饱和度，保留蓝绿对比；线上偏「墨靛」，线下偏「黛青/松烟」，比原来的 `#8b84e8` + `#2dd4cf` 更像纸墨工具，不像发光 AI 面板。

## 3. 别名桥（`limeng.css:root` 保持）

```css
:root {
  --purple: var(--accent);
  --cyan: var(--accent-offline);
}
```

`limeng.css` 的 `:root` **不要写死 hex**，只保留别名。守卫 `limeng-shell.test.mts:69-79` 会检查这一点。

## 5. 守卫常量同步（给队长）

`frontend/tests/css-vars.test.mts:164-179` 里：

- `OFFLINE_CYAN_LEGACY`：把旧青 `['#00cec9', …]` 更新为包含新黛青 `['#5f8f84', '#4e776d', '#a6c8c0']`（保留旧值与否由队长决定；建议删旧留新，避免旧色复活）。
- `LEGACY_RGB_PREFIX`：把旧 purple/cyan 的 `rgba(139,132,232,` / `rgba(45,212,207,` 前缀，更新为 `rgba(95,111,150,` / `rgba(95,143,132,`。
- `limeng-shell.test.mts` 的别名映射断言不用改，只要 `--purple: var(--accent)` / `--cyan: var(--accent-offline)` 保持。
- `ui-components.test.mts` / `materials.test.mts` 的「不得写死 hex」断言：我们的 `ui.css` 覆盖只引用 `var(--fs-*)`，不新增 hex。

## 6. 对比度粗算

| 组合 | 对比度（约） | 结论 |
|---|---|---|
| 白字 `#FFFFFF` / 墨靛 `#5F6F96` | ≈ 5.0:1 | 主按钮可用 |
| 深字 `#0B1513` / 黛青 `#5F8F84` | ≈ 5.1:1 | 线下主按钮可用 |

| 浅色 `#A6C8C0` / 背景 `#0E0E11` | > 7:1 | 线下次级文字可用 |

## 7. 无障碍要求（不能只靠颜色）

- 线上/线下仍然保留：**图标（屏幕/麦克风）+ 文字标签 + 左侧竖条**；
- 灰度打印/投屏 50% 时仍能分辨；
- 高对比度模式见 `03_高对比度规范表.md`。
