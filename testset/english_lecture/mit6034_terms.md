# MIT 6.034 术语库（英文 · 中文）

来源：MIT OpenCourseWare **6.034 Artificial Intelligence, Fall 2010**（Patrick H. Winston）的 23 个讲次官方字幕。

## 方法：课程大纲当种子 + 转写验证

**为什么不用纯统计抽术语**：第一版试过「跨讲次共现 + 词频」，产出**全是口语词**（work / equal / problem / plus / stuff / actually）—— 口语词在**每讲都高频出现**，跨讲次共现这个判据完全失效。
⇒ **统计方法抽不出领域术语，缺的是领域先验，不是统计力度。**
⇒ 改用**课程大纲当种子**：24 个讲次标题**本身就是术语表**（goal tree / alpha-beta pruning / identification tree / support vector machine / SOAR / subsumption …），再用官方 VTT **逐个验证**该术语在对应讲里真的出现。

**验证结果：52/76 个种子术语在对应讲次出现（68%）** —— 另外 24 个**没出现**，说明它们是**猜错的**（如 `and-or tree` / `inference engine` / `arc consistency`），**验证步骤有鉴别力**，不是走过场。

## 用法

这份术语库可以直接作为**产品的术语预设**（`custom_terms`），或作为
**评估侧的术语层对照组**（V7 P3 就是用它量「配了术语能救回多少」）。
